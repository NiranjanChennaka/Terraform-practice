                                 Import VS Datablock        

Use import when you want Terraform to manage a bucket that was created outside Terraform.
 Use a data block when your normal Terraform configuration needs to read an existing bucket's properties.

 import and a data block are not the same, even though both can work with existing infrastructure.

 The main difference is:
 - data block → Reads information about existing infrastructure.
 - import → Brings existing infrastructure under Terraform management by associating it with a Terraform resource in the state file.

 Interview tip: A data source reads infrastructure; import brings existing infrastructure into Terraform state for management. Neither automatically means Terraform created that infrastructure.
